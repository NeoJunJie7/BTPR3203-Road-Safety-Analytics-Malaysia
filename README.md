# BTPR3203 Road Safety Analytics Malaysia

## Overview

**BTPR3203 Road Safety Analytics Malaysia** is a Python-based data science project that analyses road accident trends in Malaysia. The project was inspired by a 2026 news report highlighting a worrying increase in road accidents, with **273,668 accidents reported between January and April 2026**. The report also noted an upward trend over recent years. citeturn0search12

The objective of this project is to use data analytics, visualization, and forecasting techniques to better understand historical road accident patterns and identify insights that may support road safety awareness and decision-making.

## Project Objectives

This project aims to:

- Analyse historical road accident trends in Malaysia.
- Identify patterns and changes in accident counts over time.
- Compare accident trends across different periods or categories.
- Visualise key findings using Python data visualisation libraries.
- Forecast future accident trends based on historical data.
- Provide data-driven insights related to the increasing concern over road safety in Malaysia.

## Research Questions

### RQ1: How have road accident trends in Malaysia changed over time?

This analysis examines historical accident data to identify whether the number of road accidents has increased, decreased, or remained stable.

A forecasting component is also used to estimate potential future accident trends based on historical patterns.

### RQ2: Are there specific years or periods with significant changes in road accident counts?

The project investigates unusual increases, decreases, and spikes in accident counts to better understand major changes in Malaysia's road safety trends.

## Running the Project

### 1. Clone the Repository

```bash
git clone https://github.com/NeoJunJie7/BTPR3203-Road-Safety-Analytics-Malaysia.git
```

### 2. Navigate to the Project Directory

```bash
cd BTPR3203-Road-Safety-Analytics-Malaysia
```

### 3. Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

### 4. Run the Analysis

```bash
python "Malaysian Road Accident Data.py"
```

Alternatively, open the Jupyter Notebook files and run the analysis interactively.
